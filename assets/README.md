# Aset aplikasi

Folder ini menyimpan aset yang dipakai langsung oleh konfigurasi Expo atau kode aplikasi. Aset referensi dan eksplorasi desain dikelompokkan ke subfolder; folder yang sudah ada tetap dipertahankan.

| File | Kegunaan |
|---|---|
| `android-icon-background.png` | Latar ikon adaptif Android yang dirujuk `app.json`. |
| `android-icon-foreground.png` | Lapisan depan ikon adaptif Android yang dirujuk `app.json`. |
| `android-icon-monochrome.png` | Versi monokrom ikon adaptif Android yang dirujuk `app.json`. |
| `favicon-android.png` | Favicon Android berukuran kecil; tidak ditemukan referensi kode langsung saat pengelompokan. |
| `favicon.png` | Favicon web yang dirujuk `app.json`. |
| `icon-android.png` | Ikon utama aplikasi yang dirujuk `app.json`. |
| `icon.png` | Varian ikon/logo; isinya identik dengan `Logo.png` dan `MouthJournal Logo in Warm Tones.png`. |
| `Logo.png` | Logo yang dipakai komponen header dan splash. |
| `onboarding_journal_collage.png` | Kolase onboarding yang dirujuk registri aset aplikasi. |
| `onboarding_wishlist_card.png` | Kartu wishlist onboarding yang dirujuk registri aset aplikasi. |
| `splash-hero-culinary.jpg` | Gambar hero kuliner untuk splash, dirujuk registri aset aplikasi. |
| `splash-icon.png` | Ikon splash; tidak ditemukan referensi kode langsung saat pengelompokan. |

## Folder

- `brand/`: panduan dan papan identitas visual.
- `food-imagery/`: gambar makanan/minuman untuk materi visual.
- `illustrations/`: ilustrasi antarmuka yang sudah ada.
- `mockups/`: mockup layar dan konsep aplikasi.
- `onboarding-designs/`: konsep visual alur onboarding.
- `source-sheets/`: lembar aset gabungan/sumber.
- `decorative/`: elemen dekoratif yang sudah ada.
